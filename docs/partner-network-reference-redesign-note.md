# Partner Network reference redesign

- Prepared on branch `ui/partner-network-reference-structure`.
- Scope is limited to the Partner Network page presentation and its local hierarchy interaction.
- The redesign uses the supplied reference only for compact visual structure; it does not introduce Branch or Sub-branch entities.
- Existing real entities remain Partner Family, Group, POSP and MISP.
- Existing Partner metrics remain available: premium this month, policies, customers, policies this month, renewals 30d and active claims.
- A local hierarchy search filters Partner, Group, POSP and MISP names/codes.
- No database, schema, API contract, deployment workflow or production configuration changes are included.
- Status: prepared only; not merged or deployed.
